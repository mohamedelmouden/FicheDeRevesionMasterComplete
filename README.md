# Fiche Master – Révision interactive
Site React + Vite généré à partir de `fiche_complète.pdf` (10 matières, sections de cours + QCM).
```
npm install
npm run dev      # développement
npm run build    # production -> dist/
```
Progression sauvegardée dans le navigateur (localStorage) ; bouton « Exporter » pour la télécharger.
